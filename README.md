# Sistema de Registro de Clientes

## Descripcion

Aplicacion web desarrollada en PHP utilizando PDO para gestionar el registro de clientes mediante una base de datos MySQL.

## Tecnologias Utilizadas

- PHP
- MySQL
- PDO
- HTML5
- Git
- GitHub
- XAMPP

## Instalacion

1. Clonar el repositorio.
2. Crear la base de datos db_sistema_web.
3. Ejecutar el script SQL.
4. Configurar la conexion en config/conexion.php.
5. Ejecutar Apache y MySQL desde XAMPP.

## Funcionalidades

- Registro de clientes.
- Consulta de clientes registrados.
- Proteccion contra SQL Injection mediante Prepared Statements.
- Proteccion contra XSS mediante htmlspecialchars().
